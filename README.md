## 📖 About

This repository serves as my personal **LeetCode journey and coding interview preparation hub**.  
It contains a collection of carefully solved problems with:

✨ Clean and optimized solutions  
✨ Multiple approaches when applicable  
✨ Time & Space complexity analysis  
✨ Pattern recognition for interview preparation  
✨ Consistent problem-solving practice  

The goal is not only to solve problems, but also to understand the **thinking process behind them**.
